Diagrams your AI agent gets right the first time.

Ask your agent for a flowchart, an architecture diagram, a sequence diagram or a chart. diagonaldiagrams draws it and checks it for overlapping text and tangled arrows, so the agent knows it's right without looking at it, and uses far fewer tokens.

Try it here Install

Checked before you see it

Every drawing is checked for text on text, text spilling out of its box, and arrows running through boxes. Most problems are fixed automatically; the rest go back to your agent with a plain fix.

Far fewer tokens

Your agent doesn't need screenshots to check its work. In our tests that meant 12.7k tokens for eight flowcharts, against 33k to 90k with other tools. See the results.

Starts from Mermaid

Agents already know how to write Mermaid, so there's nothing new to learn. To edit a diagram by hand, open it in draw.io or Excalidraw.

Results

We gave AI agents (Claude Sonnet) the same flowcharts to draw, from 5 to 40 steps, with five different tools, twice each, and counted the tokens each one spent.

Every tool ended with a readable diagram. The difference is what it cost to get there: with the other tools, the agent renders an image and looks at it, again and again as the diagram grows. With diagonaldiagrams it gets a checked result back and moves on.

Where others did better: writing the SVG by hand was cheapest for the smallest flowchart, and at 40 steps the Mermaid agents arranged their diagrams into side-by-side stages, which read better than our single long column.

How we tested
  • Every run got the same task: a process described in plain words, "make a clean, readable flowchart", and save it as an SVG. Only the tool changed.
  • The tools were Mermaid, Graphviz, D2, diagonaldiagrams with its agent instructions, and no tool at all, where the agent writes the SVG itself.
  • We counted the tokens spent on the task: what the agent wrote, what came back to it, and the images it looked at. The agent's fixed instructions are the same for every task, so they aren't counted.
  • Each size was run twice, and single runs vary by up to 2×. The agents writing SVG by hand were told not to use any drawing tool, so most never looked at their result, which keeps their count low.
  • The raw data and the counting script are in the repository.

Install

Pick the one that fits your agent. Each needs Python 3.9 or newer.

Claude Code

Adds diagonaldiagrams and the instructions Claude uses to draw with it.

/plugin marketplace add lucas19919/diagonaldiagrams
/plugin install diagonaldiagrams@diagonaldiagrams

Any other agent

Installs the diagonaldiagrams command, which your agent can run like any other.

pip install git+https://github.com/lucas19919/diagonaldiagrams

Claude Desktop, Cursor and other MCP apps

After installing the command, add it to your app's MCP servers with this command line:

diagonaldiagrams mcp
